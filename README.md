# Arduino-Based Automatic Windshield Sunshade System

## Overview
This project is a model-based Arduino system that automatically deploys or retracts a windshield sunshade based on light and temperature conditions.

## Motivation
During summer, parked vehicles can heat up quickly because direct sunlight enters through the windshield.  
This project explores a simple embedded-system approach to reduce cabin heat using automatic shading.

## Core Idea
The system collects environmental data using sensors, decides whether shading is needed, and controls a motor-based sunshade mechanism.

## Planned Features
- Light intensity sensing
- Temperature sensing
- Automatic sunshade deployment
- Manual control button
- Motor or servo-based actuation
- LED / LCD / OLED status display
- Basic state-machine logic

## Implementation Scope
This project will be implemented as a model-based MVP, not as a real vehicle-mounted product.

## Future Improvements
- Dual-roll mechanism for automatic retraction
- Limit switches for position detection
- Rain sensor for automatic retraction
- Vehicle parking-state detection
- Safety logic to prevent operation while driving
