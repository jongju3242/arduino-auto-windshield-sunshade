# Future Ideas

## Dual-Roll Sunshade Structure

A dual-roll structure may allow the sunshade to be automatically deployed and retracted without requiring the user to manually roll it back.

## Concept

The system may use two rollers:

- Upper roller: stores and rolls the sunshade
- Lower or end roller: maintains tension and guides deployment
- Motor: rotates the roller to deploy or retract the sunshade
- Limit switches: detect fully deployed or fully retracted positions

## Expected Advantages

- Automatic retraction
- Reduced user effort
- Better tension control
- More realistic product structure
- Improved usability compared to manual sunshades

## Expected Challenges

- Mechanical complexity
- Uneven rolling
- Motor torque limitations
- Wind, rain, and vibration resistance
- Interference with windshield wipers
- Safety issues during driving

## Additional Expansion Ideas

- Rain sensor for automatic retraction
- Parking-state detection
- Safety lock while driving
- Vehicle battery integration
- Mobile app or Bluetooth control
- Data logging for temperature and light changes

## Implementation Decision

The dual-roll mechanism will not be implemented in the first MVP.

The first version will focus on:

- Sensor input
- State decision logic
- Servo or motor control
- Basic sunshade movement
- Status display
